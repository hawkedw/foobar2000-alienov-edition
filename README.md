# foobar2000 Alienov edition

**foobar2000 Alienov edition beta 0.3.0** is a compact Windows desktop player with a modern x64 WPF interface and the unchanged foobar2000 0.9.6.9 x86 playback backend.

This repository has been prepared locally. No GitHub repository, tag, release or download is being announced. The complete portable ZIP is a private development artifact; third-party redistribution permissions are unresolved. Do not distribute it.

The intended authorized release consists of one complete ZIP, `foobar2000-Alienov-edition-beta-0.3.0-win-x64.zip`. Extract it to a writable directory and start `foobar2000 Alienov edition.exe`. It contains the self-contained .NET runtime, accepted playback and visualization binaries, and pinned native dependencies. It requires no separate DLL installation or first-launch component download. Clean-Windows operation of this new candidate has not been runtime verified. The next patch version is 0.3.1.
