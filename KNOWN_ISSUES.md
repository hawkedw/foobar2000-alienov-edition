# Known limits of this candidate

- No player launch is authorized in this task. New candidate playback, visualization, Telegram native loading, clean-host portability and rendered title/About layout are NOT VERIFIED.
- Static dependency closure includes x64 VC14, exact x86 VC90 and DirectX helper DLLs. Runtime activation and driver/OS compatibility need bounded later verification.
- TDLib intentionally rejects altered, unrecorded or conflicting already-loaded pinned DLLs and requires process restart after a native load attempt fails.
- Third-party redistribution rights and complete source/notice obligations remain unresolved. The package must stay private.
- The full private application source is not published. Auto-update functionality is not implemented.
