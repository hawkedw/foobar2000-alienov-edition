# foobar2000 Alienov edition beta 0.4.0

- Biography has four layouts, with B as the default, and profile-style artist images with circle and square options.
- Biography can rotate its artist gallery, filter discography from the main text, and fall back to Wikipedia when the official Last.fm biography is unavailable.
- Library Tree navigation switches MAIN more responsively, especially when opening consecutive folders.
- Search the active playlist and the Library Tree side by side. Select a result to reveal its exact row, or use Play or Jump to from the result menu.

## Portable update

Beta 0.3.10 can update the full portable package through the trusted updater. Existing settings, playlists and library data are preserved by the update contract. The bundled Last.fm application key is extractable from the desktop package and is not an account credential or Shared Secret.

The application is unsigned. Clean-Windows acceptance remains NOT VERIFIED. Existing third-party redistribution, source and notice conditions still apply. Last.fm availability varies by artist and network path.
